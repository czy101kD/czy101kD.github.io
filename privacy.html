Privacy policy

Last updated: 18 November 2026

This policy covers ReelBot, the private publishing tool used by the Once Upon A Fact channel, and this website.

Who uses ReelBot

ReelBot is used only by the creator of Once Upon A Fact, to publish the channel's own videos to the channel's own YouTube, Instagram and Facebook accounts. It is not available to the public, and it never signs in to or acts on anyone else's account.

What ReelBot accesses

  • YouTube (through YouTube API Services): permission to upload videos to our own channel and to read our own channel's basic details, such as its name, to confirm the connection works.
  • Instagram and Facebook (through Meta's APIs): permission to publish reels to our own Instagram account and Facebook Page.

ReelBot does not read, collect or store information about viewers, subscribers or followers. It does not read comments, messages, watch history or analytics.

How the access is stored

The access keys for our own accounts are stored as encrypted secrets in a private GitHub repository and are used only when the creator runs the tool. They are never shared, sold or published.

YouTube API Services

ReelBot uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access granted to ReelBot can be revoked at any time from your Google Account's third-party connections page.

This website

This site is a plain information page hosted on GitHub Pages. It uses no cookies, analytics or trackers of its own. GitHub may log basic technical information such as IP addresses for security, as described in the GitHub Privacy Statement.

Contact

Questions about this policy: send a direct message to @onceuponafkt on Instagram.
