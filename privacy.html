Privacy policy

Last updated: 18 November 2026

This policy covers ReelBot, the private publishing tool used by the Once Upon A Fact channel, and this website.

Who uses ReelBot

ReelBot is used only by the creator of Once Upon A Fact, to publish the channel's own videos to the channel's own YouTube, Instagram and Facebook accounts. It is not available to the public, and it never signs in to or acts on anyone else's account.

ReelBot uses YouTube API Services

ReelBot uses YouTube API Services to upload videos to our own YouTube channel. By using ReelBot you agree to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

What information ReelBot accesses

  • YouTube (Google sign-in with two permissions): "upload videos" (youtube.upload), used to upload our approved videos to our own channel, and "view your YouTube account" (youtube.readonly), used only to read our own channel's name to confirm the connection works.
  • Instagram and Facebook (through Meta's APIs): permission to publish reels to our own Instagram account and Facebook Page.

ReelBot does not access, collect or store information about viewers, subscribers or followers. It does not read comments, messages, watch history, analytics or any other user's data.

How the information is used, stored and shared

  • The only YouTube information ReelBot keeps is the sign-in key (a refresh token) for our own channel. It is stored as an encrypted secret in a private GitHub repository and used only when the creator runs the tool.
  • Our channel's name and the ID of each uploaded video are shown to the creator in the tool's private run log so the creator can check the result. Nothing else from YouTube is saved.
  • This information is never sold, shared with other people or companies, or published.

Cookies and device information

ReelBot does not place cookies or read or store any information on anyone's device or browser. This website does not use cookies, analytics or trackers either.

Data retention and deletion

  • ReelBot does not keep any YouTube API data beyond the run that uses it, other than the sign-in key described above.
  • When access is revoked, the sign-in key stops working immediately and is deleted from the repository.
  • To ask for any information about you to be deleted, contact us (see below). We will reply and delete it within 7 days. In practice ReelBot holds no information about anyone other than our own channel.

How to revoke access

Access granted to ReelBot can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions (also available as Third-party apps & services in your Google Account).

This website

This site is a plain information page hosted on GitHub Pages. GitHub may log basic technical information such as IP addresses for security, as described in the GitHub Privacy Statement.

Contact

Questions about this policy or deletion requests: send a direct message to @onceuponafkt on Instagram.
